Projet 01
Prédiction de l'attrition des employés à l'aide de l'apprentissage automatique : une étude de cas chez Strategics & Consulting

L'objectif de cette étude est de développer un modèle d'apprentissage automatique capable de prédire l'attrition des employés chez Strategics & Consulting. Projet 02
Tarification automobile : une-plateforme actuarielle interactive pour l'assurance-auto

Ce projet a construit une plateforme scientifique pour calculer le prix d'une assurance automobile dans un contexte où l'assureur doit fixer un prix juste pour chaque client: Trop bas sur un profil risqué → il perd de l'argent. Trop haut sur un bon conducteur → la partie client (éventuellement chez la concurrence). Ce projet implémente ce pipeline de bout en bout sur le jeu de données réel freMTPL2 (OpenML) : ~670 000 polices d'assurance auto françaises et ~26 000 sinistres associés.

R Machine Learning
Voir sur GitHub → En cours de finalisation
Projet 03 : Mémoire de fin détude pour l'obtention du diplôme d'ISE
Étude de cas en entreprise

Ce mémoire s'inscrit dans un environnement marqué par une instabilité multidimensionnelle, ce projet analyse la triple corrélation entre les conflits armés, les chocs climatiques (températures, précipitations) et l'insécurité alimentaire au Cameroun sur la période 2020-2024. L'objectif était de fournir au PAM et aux décideurs publics des preuves statistiques pour anticiper les crises et optimiser l'aide humanitaire dans les régions les plus vulnérables (Extrême-Nord, Nord-Ouest et Sud-Ouest).
